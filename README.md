# 🩺 AI Medical & Wellness Triage Assistant

Proyek ini adalah **Final Project** untuk membuat chatbot interaktif berbasis AI yang memanfaatkan kustomisasi parameter LLM (OpenAI ChatGPT API).

## 🌟 Fitur Utama & Parameter Kreatif
- **Konfigurasi Temperature (Slider):** Mengatur konsistensi dan kreativitas respon AI.
- **Pilihan Persona (System Instruction):** Mengubah gaya bahasa dan pendekatan komunikasi AI (Dokter Empatis, Praktisi Formal, Teman Sehat).
- **Fitur Context Memory (Checkbox):** Kemampuan mengaktifkan/nonaktifkan riwayat chat sebelumnya.
- **Triage Medis & Disclaimer:** Memberikan panduan evaluasi awal gejala fisik dengan proteksi etik (*guardrails*).
